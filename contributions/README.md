# 22 Code Store Contributions

This directory is the intake area for new community resources.

Each contribution should be placed in its own folder:

```text
contributions/
└── my-library/
    ├── 22-manifest.json
    ├── README.md
    └── resource files...
```

Do not place a contribution directly into `libraries/` or `scripts/`.

The automated workflow validates contributions first. After approval, a maintainer can publish the resource into the appropriate Store directory and registry.

See `CONTRIBUTING.md` for the complete requirements.
